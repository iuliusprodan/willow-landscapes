# Willow Landscapes & Groundworks Ltd

Static 5-page website. Deploy to Vercel with no build step.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `projects.html` — Projects
- `contact.html` — Get a quote

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

```bash
npx vercel --prod
```
